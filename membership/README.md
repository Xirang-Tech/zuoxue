## 会员中心视觉版本

当前采用墨黑套餐区：左侧集中展示五款产品，使用佐学官网产品图并支持放大；右侧显示套餐，手机端保留底部入口。已购用户优先继续原任务。图片元数据与业务 catalog 分开。

价格与状态演示已补齐：独立 `config/preview.json` 配置月卡 ¥99、年卡 ¥799，年卡辅助显示约 ¥66.58/月。正式 `config/catalog.json` 的价格仍为空、审核与售卖开关仍关闭。

权益对照随购买周期切换，包含到账节奏、有效期、累计上限与原会员规则。页面顶部可切换 16 个本地演示状态，体验模拟登录、确认订单、支付失败重试、开通异常、退款与恢复；不会调用真实 Identity、支付渠道、数据库或产品适配器，也不会生成付款码。

## 本地运行

四款真实产品的本地入口联调从 **http://127.0.0.1:5100/** 开始。使用独立本机数据库、合成测试账号和模拟身份服务；真实下单、支付、权益发放与 AI 调用关闭。A/B 由服务端固定，浏览器参数不能覆盖。启动、测试账号、检查结果和停止步骤见 [本地联调说明](docs/local-integration.md)。下方 5088 仍是独立的 16 状态界面演示。

要求 Node.js 22.14+、PostgreSQL 16+。前端无需构建。

```sh
cd membership
npm ci
npm run preview
```

预览地址 `http://127.0.0.1:5088`，明确标记演示价格和预览权益，不能创建真实订单。选择“未定价”可检查正式价格尚未配置时的禁购状态；选择“对照组 A”可检查入口与购买拦截。状态按本机浏览器演示 Cookie 隔离。

正式服务不会加载演示价格或开放 `/__preview/*` 与演示控制模块。现有 `GET /api/orders` 增加可空 `latest` 字段，展示当前账号最近订单的支付、关闭及退款状态，原 `pending` 字段保持兼容；不新增业务端点或数据库迁移。

新增付费墙板块可在 `http://127.0.0.1:5088/paywall-preview` 切换来源产品及 A/B 显示；原套餐区仅标示接入位置，不冒充各产品现网截图。此路径仅在本地预览进程提供。

运行实际服务时，复制 `.env.example` 为 `.env`，填写专用数据库和账号接入方配置，执行：

```sh
npm run migrate
npm start
```

数据库迁移只在显式命令执行，服务启动不创建表。月卡按 1 个日历月、年卡按 12 个日历月计算，使用 Asia/Shanghai 日历，周年日从购买日锚定；月末取目标月最后一天。

## 配置与上线

- `config/catalog.json` 是待审核模板，`approved=false`、`costApproved=false`、价格为 `null`、五款产品 `verified=false`，这些条件会阻止真实下单。
- 每款产品需要独立 `PRODUCT_CLIENTS_JSON` 凭证，以及 `PRODUCT_ADAPTERS_JSON` 指向其服务端权益接口；都不得下发到浏览器。
- 会员中心使用独立的 Identity 接入方和本域 HttpOnly Cookie，不保存密码，不共享产品 Cookie。
- 先接入全部真实权益与可靠埋点，通过联合验收，再配置价格。最后才可开启 `EXPERIMENT_ENABLED`、`SALES_ENABLED`。
- 生产使用 `NODE_ENV=production`、HTTPS、独立管理员密钥和至少 32 字符的实验 salt。外部凭证留空，不借用其他产品的身份密钥。
- 关闭实验或售卖只关闭新增入口/下单，已购权益、发放、恢复和退款任务继续运行。
- 当前退款仅支持按最新续期订单向前逐单处理；有待支付订单需先核对并关闭。退款处理中禁止再次续期。

没有为此改动课伴等产品的部署流程。新服务的域名、反向代理、证书和生产密钥需要由部署维护者配置；此仓库不包含生产密钥或默认测试账号。

## 验证

```sh
npm run check
npm test
TEST_DATABASE_URL=postgres://TEST_USER@127.0.0.1:TEST_PORT/TEST_DATABASE npm run test:db
```

数据库测试仅允许本机连接，每项测试创建并清理独立 schema。微信测试使用临时 RSA 密钥和构造的加密通知，不发起真实交易。四个产品的测试实际调用各自原生扣费实现；产品范式还通过中央订单到原生账本联调。其他三款的中央到产品 HTTP、真实商户和跨设备联调尚未完成。

测试范围包括：A 组购买拦截、跨产品固定分组、金额/币种与签名校验、支付幂等、权益事务回滚、高档与剩余额度保留、12 期发放、部分开通失败、首期额度未到账状态、退款并发、到期恢复、可靠埋点重试和包含零付费账号的收入分母。

## 实验报告

管理员接口 `GET /admin/report` 以实验版本读取已满 7 天的账号，统计五款单品加联合订单的净实收、成本、跨产品使用和样本估计。未接入单品交易与核心任务事件前，报告不可用于实验结论。

报告不自动宣布胜出。正式实验仍需预注册样本量、至少两个完整周、7 天观察成熟度和 30 天退款复查；固定期间不改变价格与权益。收入方差较大时需由分析人员复核置信区间，不能仅凭均值差上线。

产品接入与同事交接见 [接入说明](docs/product-integration.md)。
